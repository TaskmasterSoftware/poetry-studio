---
name: Custom PDF page sizes
description: Design constraints for custom page dimensions in PDF exports.
---

Custom page dimensions use inches and support sizes from 3 to 36 inches per side.

**Why:** The minimum dimension leaves printable space even with the widest existing margin preset, while the maximum prevents impractically large exports.

**How to apply:** Keep poem and book exports on the same custom dimensions and swap width and height only for landscape orientation.
